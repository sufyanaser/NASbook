# NASbook 0.9.2

## Category customization

- Expanded the built-in folder icon library from 8 to 24 icons.
- Added matching Adaptive and Colored SVG variants.
- Added media, productivity, data, security, creative, and planning icon choices.
- Preserved NASbook visual identity through minimal line geometry and a controlled Blue/Cyan/Indigo palette, with Amber and Red used only for semantic emphasis.
- Fixed blank icons in the Electron customization dialog by rendering Adaptive SVG assets inline.
- Updated the chooser to a responsive 6×4 grid.

## Validation

- Icon catalog count is regression-tested.
- Both Adaptive and Colored asset files are checked during tests.
- Lint, typecheck, automated tests, production build, and Windows installer build are required before promotion to main.
